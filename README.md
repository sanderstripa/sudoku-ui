Sudoku UI рассчитана на простую схему: **один VPS — одна панель — один сервер Sudoku**. Панель устанавливает и обслуживает собственную совместимую сборку [Sudoku Core](#совместимый-sudoku-core), создаёт отдельные ключи для устройств и показывает состояние сервера на одном экране.

Проект основан на официальном [SUDOKU-ASCII/sudoku](https://github.com/SUDOKU-ASCII/sudoku), но не является его частью.

## Быстрая установка

Поддерживаются **Ubuntu и Debian**, архитектуры **amd64** и **arm64**. Запустите от `root`:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sanderstripa/sudoku-ui/main/install.sh)
```

Это актуальная постоянная ссылка: установщик автоматически загружает последний стабильный релиз Sudoku UI и последний совместимый релиз Sudoku Core из этого репозитория.

Установщик:

1. предложит выбрать русский или английский язык;
2. установит проверенные бинарники панели и совместимого Core;
3. создаст и запустит службы `systemd`;
4. выпустит HTTPS-сертификат Let's Encrypt непосредственно для публичного IPv4;
5. создаст случайный порт, скрытый путь панели, логин и пароль;
6. напечатает готовую HTTPS-ссылку для входа.

Для первичного выпуска сертификата входящий **TCP-порт 80** должен быть свободен и доступен из интернета. Также откройте выданный установщиком порт панели. Собственный домен, DNS и Caddy не требуются.

Если на сервере уже есть Sudoku UI или Sudoku Core, установщик предложит сохранить существующее ядро, заменить его с резервной копией, выполнить чистую переустановку либо удалить управляемую установку. Обычное повторное выполнение установщика сохраняет настройки панели и учётные данные.

## Возможности панели

### Ключи и устройства

- отдельный приватный ключ для каждого устройства;
- стабильный `user_hash` без показа приватного ключа в общем API;
- состояния `enabled`, `disabled` и необратимый `revoked`;
- отключение запрещает новые соединения и закрывает активные сессии;
- удалённый ключ навсегда отзывается и больше не может быть использован;
- QR-код, `sudoku://`-ссылка и параметры для ручной настройки;
- миграция существующих ключей без перевыпуска и без изменения старых ссылок.

### Сессии и статистика

- Online/Offline и время последней активности по каждому ключу;
- список всех активных внешних IP с временем начала и длительностью;
- несколько транспортных соединений с одного IP объединяются в одно понятное подключение;
- RX, TX и общий трафик отдельно для каждого ключа;
- общая строка CPU, RAM, диска, скорости, трафика и времени работы Core.

### Управление сервером

- AEAD, четыре режима таблицы, Padding, Pure Downlink, HTTP Mask и Multiplex;
- безопасные значения по умолчанию и встроенная справка по параметрам;
- журналы панели и Core в одном окне;
- независимые версии и кнопки обновления Sudoku UI и Sudoku Core;
- проверка совместимости, контрольных сумм и автоматический откат при неудачном обновлении;
- Core обновляется только из совместимых `core-v*` релизов этого репозитория.

### Интерфейс

- русский и английский языки;
- светлая и тёмная темы;
- адаптивная вёрстка для компьютеров, планшетов и телефонов;
- встроенная классическая игра Sudoku с четырьмя уровнями сложности, заметками, подсказками, лимитами ошибок, таймером и сохранением партии в браузере.

## После установки

1. Откройте HTTPS-ссылку, которую напечатал установщик.
2. Войдите с созданными логином и паролем.
3. Создайте серверное подключение Sudoku.
4. Выпустите отдельный ключ для каждого устройства.
5. Отсканируйте QR-код либо скопируйте ссылку или параметры подключения.

Панель не создаёт подключение автоматически: порт и параметры протокола подтверждаются пользователем в интерфейсе.

## Обновления

Панель и ядро обновляются независимо из верхней строки интерфейса:

- **Панель** — устанавливает последний стабильный релиз `v*`;
- **Sudoku Core** — устанавливает только совместимый релиз `core-v*`.

Если версии несовместимы, обновление не запускается и панель показывает, что нужно обновить сначала. Конфигурация, ключи, подписки, ссылки и настройки при штатном обновлении сохраняются.

Релизы: [Sudoku UI](https://github.com/sanderstripa/sudoku-ui/releases/latest) · [все релизы панели и Core](https://github.com/sanderstripa/sudoku-ui/releases)

## Совместимый Sudoku Core

Официальный Core сам по себе не предоставляет панели данные, необходимые для управления отдельными пользователями. Поэтому Sudoku UI использует совместимую сборку на основе зафиксированного commit официального проекта и применяет патч [`core-patches/access-control.patch`](core-patches/access-control.patch).

Сборка добавляет:

- локальный API `/run/sudoku/core.sock`;
- применение политик `enabled`, `disabled` и `revoked`;
- немедленное закрытие сессий отключённого или отозванного ключа;
- активные сессии и внешний IP по `user_hash`;
- раздельный учёт RX/TX по ключам;
- постоянное хранение отозванных ключей.

Core-релизы собираются GitHub Actions из официального исходного кода с опубликованным патчем и контрольными суммами. Панель не загружает Core напрямую из upstream.

## Безопасность и данные

- приватные ключи и конфигурация хранятся локально с ограниченными правами;
- пароль панели защищён `bcrypt`;
- сессия использует `HttpOnly`/`SameSite` cookie;
- изменяющие запросы защищены CSRF-токеном;
- попытки входа ограничиваются;
- интерфейс доступен по HTTPS, случайному порту и скрытому пути;
- данные встроенной игры хранятся только в `localStorage` браузера.

Основные файлы на сервере:

```text
/usr/local/bin/sudoku-ui
/usr/local/bin/sudoku
/etc/sudoku-ui/config.json
/etc/sudoku-ui/state.json
/etc/sudoku-ui/core-version
/etc/sudoku-ui/tls/
/etc/sudoku/config.json
/etc/systemd/system/sudoku-ui.service
/etc/systemd/system/sudoku.service
/run/sudoku/core.sock
```

## Разработка

```bash
go test ./...
go vet ./...
go build -o sudoku-ui .
node --check web/app.js
node --check web/game.js
bash -n install.sh
```

Frontend встроен в Go-бинарник через `embed.FS`. CI проверяет тесты, `go vet`, сборку, синтаксис установщика и JavaScript.
